# 006 WhatsApp first, SMS fallback

**Status:** Accepted (provisional, from public-source user research; re-check in pilot), 2026-10-17

**Decision:** Parent/student notifications go through the WhatsApp Cloud API using approved utility templates from one platform number. If the message fails or the number is not on WhatsApp, send an SMS. Messages are sold as prepaid credit per institute.

**Why:** Parents read WhatsApp. Competitors mostly use SMS only. Meta charges per message since July 2025. Sri Lanka utility rates are scheduled to drop.

**Consequences:** Needs Meta business verification and template approval before launch. Opt-in/opt-out must be stored per guardian.

**Revisit when:** interviews show parents prefer SMS, or Meta pricing makes it more expensive than SMS.
