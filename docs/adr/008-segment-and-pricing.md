# 008 First segment and flat pricing

**Status:** Accepted (provisional, from public-source user research; re-check in pilot), 2026-10-17

**Decision:** First segment is individual teachers and small classes (25–300 students) running hybrid classes. Pricing: Free (50 students), Teacher LKR 2,900/mo, Institute LKR 9,900/mo, flat per plan, not per student. WhatsApp/SMS as prepaid credit.

**Why:** Biggest group, fast decisions, under-served by hardware bundles and demo-led sales. Competitors range from free (ClassFlow) to LKR 5,500–15,000/mo (eduX). Buyers dislike per-student pricing and hidden add-ons.

**Evidence:** see [STEP0_USER_RESEARCH.md](../STEP0_USER_RESEARCH.md). Competitors charge LKR 1,999–15,000/month; an A/L class earns ~LKR 1M/month, so price is not the main barrier.

**Revisit when:** after the first 3 pilot users and again at the end of the pilot.
